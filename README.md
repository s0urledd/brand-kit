# Huginn Brand Kit

Logos, colors and guidelines for Huginn — huginn.tech

## Logo

- `logo/huginn-mark.svg` — emblem, uses `currentColor`
- `logo/huginn-mark-white.svg` / `-black.svg`
- `logo/huginn-lockup.svg` — emblem + wordmark (also white/black)
- `logo/png/` — transparent PNGs (mark: 512/1024/2048, lockup: 1024/2048)
- `logo/favicon/` — favicon.ico, 32px, apple-touch 180px, 512px

Usage:

- White on dark, black on light. Don't recolor.
- Min size: 24px for the mark, 120px wide for the lockup
- Clear space: ~25% of the mark height on all sides
- No rotation, outlines, shadows or gradients

## Naming

"Huginn" is the product and validator moniker, "Huginn Tech" is the company. Never "HuginnTech".
